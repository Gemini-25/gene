# E2: 섞인 조상 (M1 기능을 쓰는 조상들을 한 세계에)

**질문.** 기록·신호·구조물을 하나씩 쓰는 공개 조상들을 한 세계에 두면, 그 후손에게서 조상에게 준 행동 너머의 새 조합(새 고수준 행동)이 나타나는가? (사용자 결정 2, 3)

- 조상: Founder-8(신호), Founder-9(기록에서 배우기), Founder-10(구조물). 셋 다 Founder-7에 습관 하나씩을 더했다(SPEC §16e).
- 한 세계에서 founder i는 i mod 3번째 조상을 쓴다(`--founder founder8+founder9+founder10`).
- 판정은 SPEC §17f의 고수준 판정기로 한다. 조상에게 준 행동은 새것으로 세지 않는다. 마지막 확인은 화면에서 사람이 한다.

### 고수준 판정 (SPEC §17f)

같은 실행을 판정기만 바꿔 다시 돌렸다. 시뮬레이션 결과(stats.csv)는 같았다.

| 판정기 | seed 1 새 family / 통과 연쇄 / 새 연쇄 | seed 2 |
| --- | --- | --- |
| 첫 판(조상 code 창 비율만) | 51 / 8 / 0 | 42 / 3 / 0 |
| 동작 순서와 상황을 본 판 | 4 / 13 / 0 | 2 / 9 / 0 |

- 첫 판의 "새 family" 대부분은 조상의 먹이 줍기를 다른 방향과 간격으로 하는 변이체였다. 예: TRANSFER G를 앞에서 세 번(간격 +5). 그래서 동작 순서(방향·양·간격을 뺀 성공한 효과 3개의 순서)가 조상 code에서 이미 나온 것이면 조상의 것으로 보게 했다.
- 남은 새 family 2..4개는 자식이 0인 번식 실패 반복이었다(COPY ↔ REPRO Resize Partial). 운반자 두셋이 두 조상 유형에 걸쳤다는 이유로 "퍼짐"을 통과했다. 그래서 퍼짐은 유형마다 운반자 3 이상을 요구하도록 고쳤다.
- 통과한 연쇄는 모두 조상의 루틴이었다. 예를 들면 다음과 같다.
  - 배아 만들기·키우기 → 복사 → 단계
  - 배아 단계 → 먹이 줍기와 먹이 신호(Founder-8)
  - 복사 → 출산·흙 줍기

**결론.** 49일(최대 31..35세대) 안에서는 조상에게 준 행동 너머의 새 고수준 행동이 나타나지 않았다. 다음을 진행 중이다.
- 같은 조상을 흙이 물을 붙잡는 물리(`gene-m2-2`)에서 돌린다(개체군이 줄지 않음, E1 참고).
- 작은 세계(128²)에서 200만 tick(수백 세대) 장기 실행(`runs/e2_long`)을 한다.

## 흙이 물을 붙잡는 물리에서 (`gene-m2-2`, 256², 같은 조건)

seed 1 (49일) 결과다. 나머지 seed는 실행 중이다.

| 날 | F8 / F9 / F10 |
| --- | --- |
| 8 | 1,162 / 615 / 1,212 |
| 16 | 1,671 / 679 / 1,707 |
| 32 | 1,447 / 529 / 1,715 |
| 48 | 1,248 / 478 / 1,562 |

- 개체 수가 `gene-m2-1`의 약 2..3배이고, 16일 이후 천천히만 준다.
- 습관 사용:
  - 먹이 신호 2.9만
  - 채택 113
  - 마지막 parcel 681
- 판정기는 처음으로 새 연쇄 1개를 냈다: #80 → #35, 개체 6, 8번, 두 상황.
  - G 앞에서 줍기 → 곧바로 배아 만들기·키우기다.
  - 두 family 모두 조상의 것이고, 연쇄만 조상 code 개체에서 보이지 않았다.
  - 조상 code로도 가능한 순서라 화면 확인(D)이 필요하다.
- 새 family 4개:
  - 2개는 자식 없는 번식 실패 반복이다.
  - 하나는 운반자 3개체의 EMIT 연발이다. 그래서 성과 연결에 운반자 5 이상을 요구하도록 고쳤다.
  - 남은 하나(#7168, 운반자 5, 성과 ×1.14, 두 유형)는 조상의 번식 절차를 다시 배열한 것이다. 배아를 만들자마자 에너지를 먼저 넣고(TRANSFER 에너지 → 배아) 나서 키운다. 조상에 없는 동작 순서이므로, 지금까지 나온 것 가운데 "새 조합"에 가장 가까운 후보다.

**화면에서 확인하는 법.** 결과가 결정론적이라 같은 설정으로 `gene serve`를 열고 재생하면 같은 세계와 같은 후보가 나온다.

```
gene serve --seed 1 --size 256 --agents 249 --founder founder8+founder9+founder10 --ruleset m2b
```

"고수준 행동 후보" 패널에서 예시 개체를 따라가 보고 ✓/✗를 누른다.

## 작은 세계 장기 실행 (128², 개체 99, `gene-m2-2`, 2,000,000 tick ≈ 488일, seed 1)

| 날 | 개체 수 | F8 / F9 / F10 |
| --- | --- | --- |
| 40 | 537 | 302 / 30 / 373 |
| 120 | 373 | 165 / 9 / 284 |
| 240 | 271 | 89 / 3 / 210 |
| 400 | 202 | 55 / 3 / 151 |
| 488 | 198 | 47 / 3 / 146 |

- 최대 세대는 90이다.
- 물·탄소는 넉넉했다. 마른 땅은 0.4% 이하였고, 공기 C는 21만에서 27만으로 늘었으며, 평균 energy는 6만대였다.
- 그런데도 개체 수가 400일까지 줄었다가 약 200에서 멈췄다. 사망의 약 80%가 하루 안에 죽는 신생아다(처음부터 끝까지 비슷). 환경이 아니라 신생아 생존과 번식 쪽 문제로 보이며, 분석이 남았다.
- Founder-9(기록 학습)는 3개체만 남았다.
- 판정기 결과:
  - 새 연쇄 1개는 무효 명령이 끼어든 번식 절차였다(조상 family의 다른 순서).
  - 새 family 1497(운반자 9, 성과 ×2.0)은 COPY의 쓰이지 않는 즉시값이 0 → 4로 바뀐 계통의 표지였다. COPY는 sub-op를 쓰지 않으므로 행동은 조상과 같다. 동작 순서 비교에서 sub-op를 쓰지 않는 효과는 sub-op를 0으로 보게 고쳤다.

**정리.**
- 지금까지 판정기가 낸 후보는 모두 조상 루틴의 변형, 실패 반복, 효과 없는 표지였다. 판정기를 고칠 때마다 이런 거짓 후보가 줄었다.
- 진짜 새 조합의 첫 후보는 `gene-m2-2` seed 1의 #7168이다(배아에 에너지를 먼저 넣는 번식 순서). 화면 확인이 필요하다.

## 신생아는 오후에 태어나 밤에 죽는다

장기 실행의 사망 51,103건 중 39,793건(78%)이 하루 안에 죽은 신생아였다. 모두 energy 부족이었고, 죽을 때 든 G는 0이었다.

| 태어난 때 | 출생 | 하루 생존 |
| --- | --- | --- |
| 새벽·오전 | 18,218 | 45% |
| 오후 | 32,976 | 10% |

- 조상은 오전에만 번식을 시작하지만, 코드가 길어(704..818 cell) 배아를 다 쓰고 내보내는 데 시간이 걸린다. 그래서 출생의 2/3가 오후로 밀린다.
- 오후에 태어난 신생아는 광합성으로 G를 모으기 전에 밤을 맞는다. 받은 energy(16,384 이상)를 유지비로 쓰다가 밤에 죽는다. E1-b에서 본 것과 같은 함정이다.
- 기존 primitive만으로 풀 수 있다. 배아 저장소(TRANSFER → Embryo)에 G를 넣으면 출생 때 자식 inventory로 들어간다. 조상의 투자 TRANSFER(r3 = 15, energy)를 복제하고 r3를 3(G)으로 바꾸는 변이 두 번이면 된다.
- 어떤 조상도 이렇게 "먹이를 챙겨 주지" 않는다. 그래서 이것이 나타나면 분명한 새 행동이다. 이를 세도록 `stats.csv`에 `provisioned`, `births.csv`에 `inv_g` 열을 더했다.

## 기록을 거친 코드 전달 (계보 수정 뒤)

계보 기록이 죽은 개체 genome의 주인을 저자로 보게 고친 뒤(SPEC §17e), `gene-m2-2` seed 2, 3에서 비혈연 코드 전달이 70건, 94건 기록됐다.
- 모두 Founder-9가 공개 기록(죽은 개체가 남긴 genome)을 초안에 베껴 채택하고 실제로 실행한 경우다.
- 가장 흔한 크기 704, 722 cell은 각각 Founder-10, Founder-8의 genome 길이다(seed 2: 19건, 12건, seed 3: 19건, 21건). 다른 조상 종류의 코드가 기록을 거쳐 문화적으로 전달된 것이다.
- 나머지(808..838 cell)는 길이가 바뀐 Founder-9 변이체의 genome이다.
- 첫 전달은 3일째에 일어났다.
- 자식에게 유전된 경우(학습한 module의 재조합)는 아직 없다.
